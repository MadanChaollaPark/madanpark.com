DESIGN NOTES / NOVEMBER 2026

Borrow the principles.
Make it your own.

A portfolio about turning curiosity into useful work. The typography, project artwork, and interactive thread sculpture were made for this site. The references below informed its scale, pacing, and restraint.

01 / Longbow

Longbow by Digital Butlers is the principal reference: a strong visual opening, generous typography, an economical interface, and a sequence that gives each project room. Here those principles serve software and systems, with original graphics rather than automotive imagery.

Four separate award platforms independently record wins for the same Longbow website. These are awards for the reference website, not for madanpark.com.

02 / BRAVIS International

BRAVIS is a secondary reference for a distinctive graphic identity and playful presentation of work. Its use of colour informed the decision to give each project here its own palette.

BRAVIS records recognition from four platforms in its award announcement: FWA of the Day, CSS Winner Site of the Day, CSS Design Awards Special Kudos and public awards, and Awwwards Honorable Mention. The CSS Winner, CSS Design Awards, and Awwwards records were checked directly. The FWA record was unavailable during this review; that award is supported by BRAVIS’s own announcement.

Made for this portfolio.

A shape with a purpose.

The line sculpture moves between an irregular loop and a more ordered form: a small expression of turning messy work into something useful. You can change its shape or pause its motion.

Work gets the space.

Four projects, four distinct treatments. Large artwork leads into readable case studies, with the original project facts retained.

Light on purpose.

Static HTML, self-hosted fonts, CSS artwork, and a small JavaScript file. No third-party scripts, animation libraries, or external font requests.

Usable by default.

Keyboard access, light and dark themes, reduced-motion support, and mobile layouts. The content and links remain usable without JavaScript.
