Policy intelligence

LobbyEar.

An agentic lobbying mention scanner over VideoDB that plans search angles, runs multimodal searches, grounds claims in transcript windows, and compiles evidence clips.

Open GitHub
Stack

Python, VideoDB, agent loop, scene/spoken indexes, FastAPI, SSE, static viewer.

  • Video AI
  • Policy
  • Agents
  • Evidence UX

Problem

Policy teams do not just need keyword hits. They need to know whether a mention matters, what source supports it, and where the exact clip can be replayed.

Approach

The agent plans 4-8 search angles from a client profile, chooses spoken or scene search, adapts query by query, records distinct mentions, and refuses to finalize until it has enough coverage.

Outcome

The result is a briefing with severity, transcript quote, why-it-matters text, an agent trace, and playable VideoDB clip URLs.
