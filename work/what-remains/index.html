Interactive fiction

What Remains.

A self-contained one-minute browser world where six irreversible choices shape a final inscription. No build step, API key, network request, or login.

Open GitHub
Constraint

Sixty heartbeats, six choices, local browser memory.

  • Static HTML
  • Interactive fiction
  • Local storage
  • Procedural sound

Shape

The game spends ten heartbeats per choice so browser latency cannot steal the intended experience. The ending is assembled from the consequences of those choices.

Why it belongs

It shows the playful edge of the portfolio: small systems can still have rules, state, pacing, and emotional consequence.
