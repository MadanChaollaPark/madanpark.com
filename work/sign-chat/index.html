Accessibility / multimodal AI

Sign Chat.

A browser app that recognizes supported ASL letters through webcam landmarks, lets users edit a sentence buffer, sends text to ChatGPT, and speaks responses back.

Open GitHub
Privacy stance

Video stays in the browser. Only user-approved recognized text leaves the machine.

  • Next.js
  • MediaPipe
  • fingerpose
  • OpenAI
  • Web Speech

Flow

Webcam frames become 21 hand landmarks, a rule-based classifier proposes letters, a stability state machine commits gestures, and the editable buffer becomes the chat prompt.

Constraint

The first version supports letters that rule-based finger curl matching can recognize consistently, while motion-heavy letters are left for future temporal modeling.
