Agent education

LearnHermes.

A staged TypeScript course for the runtime around personal agents: daemon, durable store, gateway, queue, scheduler, skills, permissions, memory, subagents, learning, and ledger.

Open GitHub
Pedagogy

Each stage starts with failing tests and intentionally incomplete runtime stubs.

  • TypeScript
  • Bun
  • Vitest
  • Fake clock
  • Agent runtime

Positioning

Not another ReAct clone. The course teaches the always-on runtime primitives most chat coding tools avoid: scheduling, state, channels, memory, permissions, and background ledgers.

Design discipline

No real network, no wall-clock dependency, mocked channels, scoped persistence, and reproducible tests make the course teach architecture instead of API luck.
