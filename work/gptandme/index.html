AI usage tooling

GPTandme.

A Chrome extension that tracks prompts sent from supported AI chat sites and stores daily, weekly, monthly, all-time, model, and session counts locally in the browser.

Privacy

No server dependency. Counts stay in local browser storage unless the user exports CSV.

  • Chrome extension
  • Local storage
  • Analytics
  • CSV export

Supported surfaces

ChatGPT, Claude, Gemini, and Perplexity. The extension only records prompt counts and available model names.

Why it fits

It is a small but clear example of product restraint: track the minimum useful signal and keep the data under user control.
