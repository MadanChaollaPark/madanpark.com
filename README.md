# Madan Park — Five Rooms, One History

An audience-routed portfolio suite for Madan Chaolla Park. The same privacy-screened proof ledger is expressed through five different editorial and interaction systems.

## Routes

- `/` — neutral curatorial index.
- `/operator/` — brutalist founder/investor/operator version.
- `/playground/` — Japanese-kawaii creative-technologist version.
- `/institutions/` — Swiss briefing-book version for policy and institutional buyers.
- `/story/` — literary memoir/media version built around *Pasta Water*.
- `/lab/` — deep-tech evidence lab for engineering and product teams.

## Content boundary

The site uses public work, owner analytics, and organizer-confirmed achievements. Private source material informed selection, but sensitive legal, family, relationship, client, commercial, and third-party information is excluded. Unverified résumé claims are not presented as facts.

## Local development

```bash
npm install
npm run dev
npm test
```

The project uses vinext and is packaged for OpenAI Sites / Cloudflare Workers.
