# Inspiration Notes

The site was planned against current high-end portfolio expectations:

- Dense first screen with identity, current focus, proof, and contact.
- Curated work over exhaustive grids.
- Case studies with constraints and outcomes.
- Optional experimental interaction in a lab, not blocking comprehension.
- Fast static pages, strong metadata, accessible navigation, and reduced motion.
- A distinctive style system tied to Madan's own NeatCode experiments.

Reference patterns considered included recent Awwwards/CSSDA portfolio sites, classic developer portfolios, and Madan's existing `madanpark.com` variants.
