# Portfolio Feature Checklist

- Clear first viewport: name, role, current focus, proof, contact.
- Featured work with problem, role, constraints, outcome, and links.
- Project index with categories, public links, and compact archive.
- Style Lab with NeatCode-derived visual modes for the whole site.
- Now panel with availability, timezone, and active work.
- Writing and lab sections for technical and strategic thinking.
- Accessible skip link, landmarks, heading hierarchy, and focus states.
- Keyboard-friendly style switching and email-copy behavior.
- `prefers-reduced-motion` support.
- Responsive layouts checked at mobile, tablet, laptop, and wide desktop widths.
- Favicon stack: SVG, ICO, Apple icon, Android icons, manifest.
- Open Graph and Twitter card metadata.
- JSON-LD for `Person`, `WebSite`, and selected work.
- `robots.txt`, `sitemap.xml`, canonical URLs, and custom 404 page.
- Fast static deployment without a JavaScript framework.
